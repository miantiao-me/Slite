# Integrations

Integrate against your own Slite domain using the [REST API](/api/). Keep `NUXT_SITE_TOKEN` on a trusted server rather than embedding it in browser extensions, public pages, or shared scripts.

For click notifications, configure [webhooks](/configuration/webhooks). For AI assistance, configure an [OpenAI-compatible provider](/features/ai). Neither integration is required for ordinary redirects or link management.

Verify third-party routes and import formats against your instance's OpenAPI schema before use.
