# 版本升级

1. 记录当前源码版本号，并妥善备份配置文件。
2. 停止容器并执行[完整数据备份](/zh-CN/features/backups)。
3. 更新至目标源码版本。
4. 执行 `docker compose up -d --build` 重新构建并启动，务必保留现有的 `/data` 数据卷。
5. 检查容器日志，登录仪表盘，验证短链接跳转与访问分析是否正常。

同一时间只允许一个进程打开数据目录。严禁新旧容器同时挂载该目录运行。如果升级涉及数据格式变更，仅回滚应用代码可能无法恢复：应停止容器，同时恢复对应的数据备份与应用版本。

## 迁移已有实例

从旧实例导出短链接数据，并在 Slite 中手动导入。在确认导入链接正常工作之前，请保持旧实例正常运行。图片文件需要单独迁移，并检查是否存在绝对路径图片 URL。链接导出不包含访问分析数据。
