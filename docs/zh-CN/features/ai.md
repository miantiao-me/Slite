# 可选 AI 支持

Slite 可通过 xsai 连接 OpenAI 兼容服务商，为短链码生成及社交分享预览提供 AI 建议辅助。常规短链接管理无需此功能。

## 启用

`NUXT_AI_BASE_URL` 与 `NUXT_AI_MODEL` 默认均为空。在两者均明确配置为 OpenAI 兼容的端点与模型之前，AI 路由直接返回 `501`，且不发起任何外部网络请求。修改配置后需重启进程。

Base URL 必须包含服务商所要求的 API 前缀路径，且所选模型必须支持对应的生成操作。若服务商无需鉴权，`NUXT_AI_API_KEY` 可以留空。

对应接口为：用于短链码建议的 `/api/link/ai`，以及用于标题和描述建议的 `/api/link/og-ai`（后者支持可选的 `locale` 查询参数）。配置完成后，若调用服务商失败，系统会自动回退至基于 URL 提取的值，而不是让请求报错。

## 数据共享说明

AI 请求仅会将你填写的目标 URL 发送至指定服务商；Slite 不会抓取网页内容。在启用 AI 之前，请确认服务商的数据留存政策与计费规则，切勿提交敏感私密信息。若生成失败，请检查端点地址、模型可用性、凭证以及容器的外网连通性。
