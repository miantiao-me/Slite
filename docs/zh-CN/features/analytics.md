# 访问分析与近实时视图

Slite 内置基于 [DuckDB](https://duckdb.org/) 的本地访问分析引擎。所有访问事件均存储在本地的 `/data/analytics.duckdb` 文件中，无需依赖任何第三方服务、云平台账号或外部 API 密钥。

## 记录的数据维度

每次短链接访问事件会记录以下信息：

- **网络层面：** 完整的客户端 IP 地址、来源站点（Referer Host）以及来自 `Accept-Language` 的首选语言。
- **客户端环境：** 解析出的浏览器名称、操作系统以及设备类型（桌面、移动端、平板）。
- **地理位置：** 根据本地 GeoIP 数据库解析出的国家/地区、省州、城市及大致经纬度坐标。

::: warning 个人数据隐私与留存政策
由于 Slite 完整记录了客户端 IP 地址，请将 `/data/analytics.duckdb` 视为包含个人数据的文件妥善保管。

Slite 当前未内置按时间自动清理历史分析数据的机制。访问事件会一直保留在该文件中，直到文件被手动归档、替换或删除。运维人员应根据自身适用的合规要求制定并公示数据留存和用户告知政策。
:::

如需从访问统计与[点击 Webhook](/zh-CN/configuration/webhooks) 中剔除爬虫与机器人流量，请设置 `NUXT_DISABLE_BOT_ACCESS_LOG=true`。

## 仪表盘统计功能

仪表盘通过聚合查询本地 DuckDB 数据展示多维图表：

- 访问总量、独立访客趋势与每日分布热力图。
- 热门来源站点与搜索引流域名。
- 设备类型、浏览器、操作系统及地理分布饼图和排行列表。
- 支持按短链码、时间跨度、国家、设备及来源进行组合筛选。

受保护的 `GET /api/logs/events` 接口向仪表盘提供最近访问记录，且会在输出时脱敏剔除 IP 地址字段。

## 地理位置解析与 GeoIP

地理分布图表依赖本地加载的 GeoIP 数据库：

- 官方 Docker 发布镜像已内置 **DB-IP City Lite** 数据库（遵循 CC BY 4.0 许可），国家、地区、城市与坐标分析开箱即用。
- City Lite 数据库不包含时区与邮政编码信息，Slite 绝不会无据推测或虚构时区数据。
- 若环境中未找到有效数据库，查询会遵循**平稳回退**机制：地理字段保持留空，短链接重定向与核心统计照常进行。

数据库加载优先级说明见 [GeoIP 数据库](/zh-CN/deployment/docker#geoip-database)。

## 近实时 3D 地球视图

实时仪表盘提供了交互式的 3D 地球视觉效果，动态展示全球各地的访问事件。

::: tip 并非 WebSocket 长连接
该实时界面并未采用 WebSocket 或 SSE 协议。仪表盘大约每 10 秒轮询一次 DuckDB 抓取最新增量事件，并通过客户端队列以大约每秒一条的节奏平滑回放动画。

点击暂停或切换离开浏览器标签页时，轮询、回放队列与 WebGL 渲染均会自动暂停。
:::

## 统计报表导出

你可以在仪表盘中直接下载根据当前筛选条件生成的 CSV 报表文件，亦可通过统计导出 API 获取。CSV 导出包含短链码、目标 URL、访客数、点击量以及主要来源等聚合汇总。

短链接本身的配置导出为独立功能，详见[导入与导出](/zh-CN/features/import-export)。
