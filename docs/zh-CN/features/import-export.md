# 导入与导出

通过携带鉴权信息的 `/api/link/export` 与 `/api/link/import` 接口，可在兼容的实例间迁移短链接。请求时须携带请求头 `Authorization: Bearer YOUR_SITE_TOKEN`；参见 [API 参考](/zh-CN/api/)。

## 导出

导出接口以 JSON 分页形式返回数据。根据返回的 cursor 继续请求下一页，直至 `list_complete` 为 true。请保留每一页数据。导出的记录包含链接配置及受保护的密码哈希，而非明文密码。

## 导入

在 API 请求体限制内分批提交记录。请检查每条记录的处理结果，并在排查解决原因后再重试失败项。

- 支持导入已过期的记录。
- 遇活跃短链码冲突时跳过，不覆盖已有记录。
- 短链码大小写遵循目标实例的设置。
- 支持导入兼容格式的受保护密码；控制面板中脱敏显示的占位符并非有效密码。

## 迁移已有实例

从原有实例导出数据，并手动导入到 Slite 中。在确认导入链接均能正常访问前，请保持原部署继续运行。

链接导出数据不包含进程内可随时重建的内存缓存、访问分析、上传的图片文件或完整的应用状态快照。内存缓存无需恢复。图片文件需单独复制，并检查是否存在仍指向原主机的绝对地址。在完成重定向和密码保护链接的验证前，请保留原系统。已有 Slite 实例的完整备份请参考[停机并复制 `/data`](/zh-CN/features/backups)。
