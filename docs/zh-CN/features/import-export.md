# 导入与导出

通过携带认证信息的 `/api/link/export` 与 `/api/link/import` 接口，可在兼容的 Slite 与 Sink 实例之间高效迁移短链接。

API 请求必须携带你的站点令牌：

```http
Authorization: Bearer YOUR_SITE_TOKEN
```

## 数据导出

导出接口以 JSON 分页形式从权威 SQLite 数据库提取记录：

- 持续使用响应中返回的 `cursor` 请求下一页，直至 `list_complete` 为 `true`。
- 每条记录包含完整的路由分流规则、创建时间、标签、备注、社交预览元数据以及**受保护的密码哈希**（绝不会暴露明文密码）。
- 导出接口使用固定的每页 50 条记录。

迁移或归档时请妥善保留所有导出的 JSON 分页文件。

## 数据导入

导入接口支持分批提交 JSON 记录，单次 API 请求上限由 `NUXT_IMPORT_REQUEST_LIMIT` 决定（默认为 100 条）。

在前端仪表盘中，`NUXT_PUBLIC_IMPORT_BATCH_LIMIT`（默认 50）用于控制客户端导入分批大小，单次请求最多携带该值的一半（默认 25 条）。

- **格式校验：** Slite 在持久化前会严格校验批量数据的 Schema 格式，并按条目返回处理结果（`success`、`skip` 或 `fail`）。
- **冲突处理：** 遇到已存在的活跃短链码时自动跳过，不覆盖现有数据。
- **过期记录：** 允许导入已过期的短链接，以便完整保留历史归档。
- **大小写规范：** 导入的自定义短链码遵循目标实例的 `NUXT_CASE_SENSITIVE` 大小写规则。
- **受保护密码：** 从兼容的 Slite 或 Sink 导出的受保护密码哈希可直接导入生效，无需知晓原始明文。仪表盘界面中脱敏展示的占位符不是合法密码，会被校验拒绝。

## 迁移已有实例

跨服务器迁移或从旧实例迁入短链接时：

1. 从原实例分页导出全部短链接 JSON 文件。
2. 通过导入接口或仪表盘将 JSON 文件分批导入新 Slite 实例。
3. 将原实例 `files/images` 目录下的图片文件手动复制到新服务器对应位置。
4. 在新实例充分验证重定向与密码访问正常之前，请保持原实例正常运行。

::: tip 导入并非全系统还原
短链接导出数据不包含 DuckDB 访问分析日志、进程内内存缓存以及上传的图片二进制文件。

进程内短链接内存缓存会在访问时自动从 SQLite 回填，无需恢复。若需获取包含短链接、分析数据与图片在内的完整系统镜像，请执行[停机冷备份 `/data`](/zh-CN/features/backups)。
:::
